# spending-tracker

無駄遣いと、回避できた支出をすばやく記録するブラウザ/PWAアプリです。

## 特徴

- 150円、300円、1,000円、4,000円をワンタップで記録
- 任意金額も入力可能
- 無駄遣い・回避・差引効果を分けて集計
- 今日・今週（月曜始まり）・今月・今年・累計を表示
- 記録直後の取り消し（Undo）
- 直近10件の履歴表示、個別削除、任意メモ
- 直近6か月の差引推移
- JSONバックアップ／復元、CSV書き出し
- データはブラウザの `localStorage` のみに保存
- Service Workerによるオフライン利用に対応
- ビルド工程や外部ライブラリなし

## 記録データ

各記録は次の情報を持ちます。

- `id` — 記録ID
- `amount` — 金額。無駄遣いは負、回避は正
- `createdAt` — ISO 8601形式の記録日時
- `note` — 任意メモ（最大200文字）

保存キーは `spending-tracker.records.v3` です。v2の記録がある場合は初回起動時にv3へ移行します。

## バックアップ

「データ管理」からJSONバックアップを保存・復元できます。復元は現在のデータをバックアップ内容で置き換えます。CSVはExcel等での集計用です。

## 構成

- `index.html` — マークアップ
- `styles.css` — 表示とレスポンシブ対応
- `app.js` — 記録、保存、集計、履歴、バックアップ
- `service-worker.js` — PWAキャッシュ
- `manifest.json` — PWAメタデータ
- `icons/` — PWA・favicon用画像

## ローカル実行

Service Workerを含めて確認する場合は、リポジトリのルートで簡易HTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。
