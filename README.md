# spending-tracker

無駄遣いと、回避できた支出をすばやく記録するブラウザ/PWAアプリです。

## 特徴

- 150円、400円、1,000円、3,000円を初期値としてワンタップで記録
- 4つのクイック金額はユーザが自由に変更可能
- 2秒以内の連続入力は1件に合算し、合計0円なら記録を取り消し
- 任意金額も入力可能
- 無駄遣い・回避・差引効果を分けて集計
- 今日・今週（月曜始まり）・今月・今年・累計を表示
- 記録直後の取り消し（Undo）。連続入力を合算した場合はまとまり全体を取り消し
- 直近10件の履歴表示、個別削除、任意メモ
- 直近6か月の差引推移
- JSONバックアップ／復元、CSV書き出し
- データはブラウザの `localStorage` のみに保存
- Service Workerによるオフライン利用に対応
- ビルド工程や外部ライブラリなし

## クイック金額

初期値は `150 / 400 / 1,000 / 3,000円` です。「クイック金額設定」から4つの金額を変更でき、設定は `spending-tracker.quick-amounts.v1` としてブラウザの `localStorage` に保存されます。

設定できるのは1〜100,000,000円の異なる4つの整数です。「初期値に戻す」で初期値へ戻せます。

## 連続入力

同じページを開いている間、前回の入力から2秒以内に次の金額を記録すると、1件の記録として合算します。たとえば `-1,000円` を2回続けて押すと `-2,000円` の1件になります。`-1,000円` の直後に `+1,000円` を入力した場合は合計0円となるため、その記録自体を取り消します。

連続入力は前回の入力から2秒のスライド式で判定します。日付をまたぐ場合、ページを再読み込みした場合、メモを編集した場合、履歴を操作した場合は新しいまとまりとして扱います。

## 記録データ

各記録は次の情報を持ちます。

- `id` — 記録ID
- `amount` — 金額。無駄遣いは負、回避は正
- `createdAt` — ISO 8601形式の記録日時
- `note` — 任意メモ（最大200文字）

保存キーは `spending-tracker.records.v3` です。v2の記録がある場合は初回起動時にv3へ移行します。

## バックアップ

「データ管理」からJSONバックアップを保存・復元できます。復元は現在のデータをバックアップ内容で置き換えます。CSVはExcel等での集計用です。

## 数理設計ノート

- [クイック金額配置の数理設計](docs/quick-amount-mathematics.md) — 符号付き反復入力を最小タップ問題として定式化し、基数経済性、ネイピア数 `e`、平衡記数法、既定値 `150 / 400 / 1,000 / 3,000円` の位置づけを整理しています。

## 構成

- `index.html` — マークアップ
- `styles.css` — 表示とレスポンシブ対応
- `app.js` — 記録、保存、集計、履歴、クイック金額設定、バックアップ
- `service-worker.js` — PWAキャッシュ
- `manifest.json` — PWAメタデータ
- `icons/` — PWA・favicon用画像
- `docs/` — 設計ノート

## ローカル実行

Service Workerを含めて確認する場合は、リポジトリのルートで簡易HTTPサーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。
